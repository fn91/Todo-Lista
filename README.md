# 📝 Lista de Tareas 2025

Una aplicación web minimalista, elegante y funcional para gestionar tus tareas del día a día. Crea, completa y elimina tareas con estilo, sin complicaciones.

## 🚀 Características

- Añadir tareas rápidamente.
- Marcar tareas como completadas con un clic.
- Eliminar tareas individualmente.
- Interfaz moderna, limpia y responsiva.
- Experiencia de usuario pulida con animaciones suaves.

## 📁 Estructura del Proyecto

📦 ListaTareas2025
├── index.html # Estructura principal de la app
├── style.css # Estilos personalizados con diseño moderno
└── script.js # Lógica para gestionar tareas



## 🧠 Tecnologías utilizadas

- HTML5
- CSS3 (con diseño responsive y animaciones)
- JavaScript puro (sin dependencias)
